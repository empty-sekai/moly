# R5 browser delivery closeout — 2026-09-16

This is the current completion record for the browser integration. Earlier
handoff/TODO records describe earlier snapshots and are historical evidence.

## Delivered behavior

- One trusted outer Play/Preview click starts the existing prepared stage and
  its single audio context. Preview consumes the independent original tweet;
  engagement enters the full native dialogue without rebuilding its scene.
- Original balloon and talk-window geometry, source line breaks, glyphs and
  atlas textures are used in browser and native presentation. Mobile retains
  the authored canvas scaling rather than inventing a different dialogue UI.
- `moly-root-chara-head-v1` uses actual chara viewer head-only geometry. All
  31 units per region have 512-square transparent RGBA portraits with source,
  model, rig and output hashes. Two full exports per region matched byte for
  byte. Long hair may exit the bottom; crown and side boundaries are clear.
- The host shows all participating heads together with the furniture texture,
  uses 24-entry pages with history, preserves selection scroll, and keeps the
  same iframe through both fullscreen modes and locale changes. Ordinary
  furniture pages request no WASM or runtime GLB.
- Player JSON preview/explore/restore uses a bounded transient operation and
  leaves persistent localStorage unchanged. The original layout returns.
- Necessary resources prepare automatically. The narrowly scoped cache has
  bounded storage/admission, protects necessary assets, supports scoped clear,
  and recovers from storage failure without blocking successful online loads.

## Actual limits

The cache covers retained resources, not the entire site shell, unseen content,
or remote player-data calls. Browsers may evict storage. This matrix covers
representative exact-source content, not every dialogue in both catalogues.
Portrait pixel identity is tested on the recorded Chrome/GPU environment;
different GPUs/browser versions may rasterize differently. Mobile source text
is small because source canvas geometry is preserved; fullscreen is available.
One simultaneous JP initialization exceeded an old QA script's 30-second
default, then passed unchanged in isolation; final published tests passed.
Native interactive input was not visually retested in this browser-focused run.

The initial workspace contained unrelated edits and a superseded native portrait
experiment. Those files were preserved and left uncommitted. The build fingerprint
therefore describes exact dirty working-tree inputs, not a clean Git checkout.
No reset/clean or blanket staging was used. Only reviewed feature files/hunks
were committed. This delivery publishes local QA artifacts; it does not deploy
to a public service or push repository history.
