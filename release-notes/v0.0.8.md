# moly 0.0.8

这一版修复对话结束后家具动作的几个问题，改进对话镜头，并允许从本地目录读取主表。

> [!IMPORTANT]
> moly 仅供学习研究与本地单机使用，目标不是替代原版游戏的客户端或服务器。仓库与发布包不含任何游戏资源、提取工具或原版客户端代码；随附的服务端是 moly 自己的实现，只服务于 moly 的客户端。详见 README 开头的「使用前必读」。

## 修复

- 角色走到家具的动作起点后、开始播放家具动作之前，不再闪一帧初始姿势（T-pose）。
- 内容库独立模式里，暂时离场的角色改用与 NPC 隐藏相同的方式隐藏，不再被重叠检查算进去，家具动作不会因此一直不开始。
- 对话后的家具动作期间，参与的角色保持被占用；有角色中途被放开时，动作立即失败并给出角色编号。
- 内容库把角色与观察位置放在家具的使用一侧，而不是家具背后。

## 镜头与主表

- 对话镜头在两次取景之间绕目标转过去，不再从目标身前穿过；`camera.talk_lens` 新增 `reach`，限制单人与家具同框时镜头后退的最远距离。
- 没有对话时，镜头从正面拍指定角色，有家具挡住时稍微偏开；挡住视线的家具按部件逐个淡出，只淡出挡住的那部分。
- 桌面版的主表来源可以写成以 `/` 结尾的本地 `file://` 目录，目录结构与主表服务器相同，见 `docs/masters.md`。

## 程序包与文档

- Windows 程序包改为在 Linux 上交叉编译，C 与 C++ 运行库静态链接，不再需要另装 Visual C++ 运行库；macOS 程序包在最新的 macOS 构建机上编译。
- README 的「完成情况」补上访客门、站点扩展、家具叠放编辑、背包的页签／筛选／排序／分解、软粒子与拖尾，「已知限制」随之更新。

## 下载

- Windows x64、Linux x64、macOS Apple Silicon：下载对应平台的游戏包，包含游戏、启动器与服务端；独立服务端仍有单独的包。
- 运行启动器，配置**你自己的**资源地址，选择资源版本并下载。
