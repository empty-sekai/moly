# moly 0.0.7

这是 moly 的最后一个版本，发布后仓库归档：不再增加功能，也不再修复问题。这一版加入序列播放器、布娃娃和可调阴影，修复了已知的启动与界面问题，并把文档更新为现状。

> [!IMPORTANT]
> moly 仅供学习研究与本地单机使用，目标不是替代原版游戏的客户端或服务器。仓库与发布包不含任何游戏资源、提取工具或原版客户端代码；随附的服务端是 moly 自己的实现，只服务于 moly 的客户端。详见 README 开头的「使用前必读」。

## 序列与布娃娃

- 新的序列文档（JSON）按秒、按台词、按标记或相对另一段来定时，描述镜头、角色移动与朝向、动作、表情、视线、声音、台词、字幕、画面效果和事件，格式见 `docs/sequence.md`。
- 游戏里可以载入并播放序列：`moly.sequence.load|play|pause|seek|speed|stop|status|schema`，以及 `sequence.play`、`sequence.stop` 两个步骤。暂停时可以用自由相机取景，再用 `moly.sequence.key` 把当前镜头写回文档。
- 角色可以作为布娃娃倒下，静止后在落点重新站起：`moly.ragdoll.drop|recover|status|settings|schema` 与 `npc.ragdoll` 步骤，说明见 `docs/ragdoll.md`。

## 画面与工具

- 主光源阴影可以在 `moly.toml` 的 `[graphics]` 节设置，也可以在运行中用 `moly.graphics.get`、`moly.graphics.set` 调整：阴影图分辨率、覆盖范围、距离与淡出、过滤方式（`hard`、`tent`、`pcf`、`pcss`）和偏移。
- 阴影边缘改为双线性比较采样，不再按整个纹素出现台阶；角色明暗在存储值上计算，暗部颜色按完整强度生效。
- 使用角色着色程序的家具部件（例如足浴里泡着的腿）能正常绘制。
- 开发工具可以把窗口画面与游戏混音录成 MP4（`moly.record.start|stop|status`），说明见 `docs/recording.md`。
- 对话镜头支持缓动、推近，并会淡出挡住视线的家具；`moly.director.schema` 列出全部已注册的步骤。

## 修复

- 拍照界面打开时不再崩溃（[#28](https://github.com/empty-sekai/moly/issues/28)）。
- 服务端的控制端口可以设为 0 由系统分配；启动器、MCP 服务器与气泡检查都这样启动服务端，默认端口被占用时游戏不再启动失败（[#26](https://github.com/empty-sekai/moly/issues/26)）。
- 状态机里目标结束时，角色的决策不再无限重抽；被宿主接管的角色不再被拉进 NPC 对话；NPC 的计时与行走跟随游戏时钟的倍速、暂停与单步。
- 表情粒子的拉伸方向沿运动方向；对话镜头按身体而不是根节点取景；整洁视图隐藏 HUD 时同时隐藏动作按钮；关闭内容库的浏览器时保留场景。

## 文档与支持范围

- README 改为「完成情况」与「已知限制」两节，路线图与贡献指南已移除。
- Android 不再受支持，构建文件只作参考保留，发布包里没有 Android 版本；Linux 与 macOS 版本没有在真机上验证。

## 下载

- Windows x64、Linux x64、macOS Apple Silicon：下载对应平台的游戏包，包含游戏、启动器与服务端；独立服务端仍有单独的包。
- 运行启动器，配置**你自己的**资源地址，选择资源版本并下载。
