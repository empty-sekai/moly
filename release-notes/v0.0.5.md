# moly 0.0.5

这次更新主要围绕日服 7.0.0 的交互还原：加入插件系统与脚本伙伴，接通跨团对话，补齐道路／地砖和天气编辑界面，并加入一键清图的大锤采集。网页嵌入舞台也拆成独立程序，显示文本可以在保留日服演出的同时使用中文覆盖。

## 插件系统与脚本伙伴

- 原生端可以加载 Luau 插件，通过 `plugin.toml` 声明版本、依赖与冲突，并在个人配置中选择启用；默认不启用任何插件。
- 插件可以读取场景状态、订阅事件、安排异步任务、调用游戏动作，并保存各自的数据。每个插件有独立沙箱、内存限制和每帧执行预算。
- 提供问候示例和脚本伙伴示例：伙伴可以行走、敲锤建造家具、转向玩家作出反应，并使用刚建好的家具。示例源码位于仓库的 [`plugins/`](https://github.com/empty-sekai/moly/tree/v0.0.5/plugins)；安装后需在个人配置中启用。

## 日服 7.0.0 与编辑界面

- 接入新的分层 NPC 状态机和不同团体角色之间的对话，保留角色移动、动画、对话条件和场景恢复逻辑。
- 道路／地砖页支持选择样式、规划铺设、确认与取消、选中移动、收回和保存；库存与已放置对象随同一份布局事务更新。
- 天气页使用源资源的图标和选项，按已解锁内容选择环境，并与布局一起保存或放弃。
- 修复列表无法滚动、滚动条拖动无效，以及编辑操作结束时相机被一并拖动的问题。

## 一键清图：大锤采集

- 加入长按蓄力、取消、采集目标设置和奖励界面，接入大锤模型、材质、演出时间轴、蓄力条、特效与音效。
- 采集仍遵循通行资格、体力、工具耐久和掉落结算规则；取消不会提前扣除消耗。
- 修复宝箱投递后无法再次使用大锤，以及错误出现“通行证过期”提示的问题。

## 独立网页舞台与中文文本

- 嵌入舞台拆为独立的 `moly-stage` crate，保留对话、家具演出、角色互动、天气与布局预览所需的系统。完整游戏另行提供。
- 网页选择中文时，可以用匹配的国服官方文本替换日服显示文本；日服场景、角色、语音和演出保持原样，没有匹配译文时显示日文。
- 文本包、字体包与资源快照分别版本化；译文更新无需替换 Lua，也不需要让整个资源快照失效。
- 社区翻译上传后台另行审核，本版本不包含该服务的上线。

## 稳定性与运行基础

- 升级至 Bevy 0.19.1，修复空网格复制、无名称 glTF 场景根节点和天气后处理顺序的问题。
- 将行走区域生成移出主线程，减少重复的工具提示准备，并修复相关音效交付与浏览器音频调度问题。
- 使用开源的 Resource Han Rounded 字体，原生和网页包均附带 SIL Open Font License。

## 下载与升级

- Windows x64、Linux x64、macOS Apple Silicon：下载对应平台的游戏包，包含游戏、启动器与服务端。独立服务端仍有单独的包。
- 网页包拆为 `moly-0.0.5-web-stage.tar.gz`（嵌入舞台）和 `moly-0.0.5-web-game.tar.gz`（完整游戏），各含 WebGPU 与 WebGL2 构建。部署方需更新原先单一 `web.tar.gz` 的路径。
- 游戏资源单独提供，不包含在程序发布包内。体验上述日服新增内容需要配套的 JP 7.0.0 资源；网页资源上线状态以站点当前提供的版本为准。
- 解压到新目录后通过启动器运行；保留原安装目录和存档。升级及目录迁移方式见[发布包说明](https://github.com/empty-sekai/moly/blob/v0.0.5/docs/release-package.md)。

本轮原生编辑与采集功能已由维护者实际体验验收。Linux、macOS 的构建通过不代表实机验收；WebGL2 提供构建，但本轮不宣称已完成播放验收。
