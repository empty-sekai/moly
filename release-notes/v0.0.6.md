# moly 0.0.6

这次更新把程序设置收进一个配置文件 `moly.toml`，程序不再内置任何网络地址；同时按玩法域拆分 crate，升级到 Bevy 0.20，并加入布局、视图与采集的导演步骤和两个新插件。

> [!IMPORTANT]
> moly 仅供学习研究与本地单机使用，目标不是替代原版游戏的客户端或服务器。仓库与发布包不含任何游戏资源、提取工具或原版客户端代码；随附的服务端是 moly 自己的实现，只服务于 moly 的客户端。详见 README 开头的「使用前必读」。

## 配置文件与地址

- 启动器、游戏、开发窗口和服务端的设置都从数据目录里的 `moly.toml` 读取（也可以用 `MOLY_CONFIG` 指定文件）；每个键保留原来的环境变量作为覆盖。未知的键或类型不对的值会让程序停止启动，并指出是哪个键。
- 开发开关是 `[dev]` 键，显示文本的翻译文件是 `[text]` 键。`docs/configuration.md` 与 `moly.example.toml` 列出全部键。
- 程序不再内置资源、主表、玩家数据或服务端的地址：都需要在 `moly.toml` 或环境变量里自行配置，没有配置的功能会拒绝运行并指出对应的键。启动器在填入资源地址之前不会下载；网页版必须用 `?server=` 指定服务端；安卓包在构建时指定资源地址与服务端。

## 导演步骤与插件

- 新增 `layout.free`、`layout.clear`、`layout.put`、`layout.put_many`、`layout.remove`、`view.set` 与 `companion.gather` 步骤；`docs/plugins.md` 记录了 Luau 接口和全部导演步骤。
- 每个站点可以打开自由布局模式；布局步骤经过编辑器自己的检查后保存。
- 伙伴可以采集采集物，使用玩家自己采集时会选的工具；建造落在指定的格子上，并报告保存后的格子。
- 新插件 `moly.home-build`（伙伴依次建造排好的家具并一起做出反应）和 `moly.talk-shot`。
- 新增隐藏 HUD 与隐藏玩家身体的开关；开发工具可以跟随说话的角色，并在画面上显示家具动作失败的原因。

## 修复

- 眼睛贴图按表情行的贴图编号切换，眼睛覆盖层改为半透明的第二层；眉毛不再透过挡住角色的物体显示；泳池和浴池的水面不再被地面盖住。
- 伙伴从最近的导航格出发而不再瞬移，沿路径走到目标，导航重建后重新出发；障碍物只在状态改变时重建挖空区域，行走的角色不再每帧重新规划路线。
- 采集掉落落在着地点的行走面高度上；体力条跟随服务端修改后的体力。
- 启动器取消资源下载时，正在传输的文件会在读到的那一块后立即停止，不再等整个文件下完；按下取消后按钮显示「正在取消…」。
- 启动器下载资源时打开的连接数不再超过「并行下载」的设置，每个传输线程复用自己的连接，不再每个文件都新建一次连接。

## 工程

- 升级到 Bevy 0.20。
- 转换、任务、拍照、家具编辑、配送、采集、内容库和过场演出拆成各自的 crate，安装进 `moly-features`。
- 持续集成检查 crate 分层与各项 lint 警告数，API 文档在不允许警告的条件下构建，测试覆盖整个工作区。

## 下载与升级

- Windows x64、Linux x64、macOS Apple Silicon：下载对应平台的游戏包，包含游戏、启动器与服务端；独立服务端仍有单独的包。
- 运行启动器，配置**你自己的**资源地址，选择资源版本并下载。旧版本的 `launcher.json` 会在第一次启动时导入 `moly.toml`。
